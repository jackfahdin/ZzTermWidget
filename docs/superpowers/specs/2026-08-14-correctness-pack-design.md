# 正确性修复包（kitty 逐行切片 / DECDH 几何根治 / SGR 38/48 冒号真彩）设计规格

日期：2026-08-14
状态：已批准（头脑风暴结论）
来源：轮 6 终审 I-4（kitty DECSTBM 切割错位）、轮 7 终审登记（DECDH 墨迹 2× 行坐标）、轮 8 遗留（argSeparators 就位后的 38/48 冒号真彩）

## 1. 背景与目标

三个小型正确性修复打包为一轮（共享一轮审查开销）：

1. **kitty 逐行切片**：轮 6 kitty 放置绘制采用"任意引用行回推锚定行画整图"，依赖放置覆盖行的行一致性；DECSTBM 部分滚动区（或 insertLine/deleteLine）切割跨边界放置后行一致性破裂，图像绘制错位（sixel 逐行切片无此问题）。
2. **DECDH 几何怪癖**：双高行（`ESC#3`/`ESC#4`）绘制时 `calculateTextArea` 只逆映射原点，`scale(1,2)` 世界变换下墨迹落在 2× 行坐标处——任何行矩形脏区都盖不住墨迹，增量重绘必留残影（轮 7 因此把双高行排除在像素等价之外）。
3. **SGR 38/48 冒号真彩**：轮 8 已为 SGR 建成 `argSeparators` 子参数设施；`38:5:n`/`38:2::r:g:b`/`48:*` 冒号形式仍按拍平误解（`38:2::1:2:3` 被读成 RGB(0,1,2)+斜体），低成本补齐。

## 2. 范围

包含：

- kitty 放置绘制改逐行水平带切片 + DECSTBM 切割回归测试。
- DECDH 行坐标逆映射根治（含双高双宽组合核对）+ 双高行像素等价测试（批次 vs Legacy + 增量重放）。
- SGR 38/48 冒号子参数形式（`38:5:n`、`38:2::r:g:b`、`48:5:n`、`48:2::r:g:b`）+ 解析测试。

明确不做（YAGNI）：

- kitty 动画、Unicode 占位符、相对放置（既有遗留，不动）。
- DECDH 在备选屏/缩放中的特殊行为扩展。
- ISO 色彩空间标识的精确解释（冒号空位容忍即可，与 58 口径一致）。
- sixel 绘制路径（本就是逐行切片，不动）。

## 3. 详细设计

### 3.1 kitty 逐行水平带切片（TerminalDisplay）

- `drawKittyPlacements` 从整图绘制改为逐行带切片：对每个引用行，只绘制放置目标矩形中 `ref.rowOffset` 对应的水平带——目标带 = 该行的单元格行带与放置目标矩形的交集；源带 = 源矩形中按目标高度比例的对应水平条。
- 每行独立计算，消除行一致性假设：DECSTBM 切割后，滚动区内外各段的引用行各自落在正确视图行，图像随文本切割（与 sixel 行为一致）。
- 带天然落在各自行 rect 内：轮 6 F2 的多 rect 半透明重复混合边角顺带消除（`seenHandles` 去重逻辑可随切片重构简化或保留防御，以实施时代码评审为准）。
- 不变项：z 层双通道（z<0 文本下层 / z≥0 文本上层 + 光标复绘）、X/Y 单元格内偏移、c/r 缩放、源矩形取交、超右缘截断、同 z 按 id 排序。
- 测试：既有 kittygraphics/rendering 用例保持绿；新增 DECSTBM 部分滚动切割用例（滚动区横切放置中部，滚动后断言上下两段像素各归其位）。

### 3.2 DECDH 绘制几何根治（TerminalDisplay）

- 修正双高行的行坐标→像素坐标换算：使 `scale(1,2)` 世界变换下的墨迹落在该行自身的行带（而非 2× 行坐标）；`calculateTextArea` 的原点/高度逆映射一致化。双高双宽（DECDWL 组合）一并核对。
- 修复后双高行纳入轮 7 增量重放像素等价的适用范围（行矩形脏区能盖住墨迹）。
- 绘制内部其余逻辑不动；斜体/下划线手绘/图像叠加与双高行的组合行为以像素测试裁决。
- 测试（补轮 4 登记的分支覆盖缺口）：
  - 双高行批次 vs Legacy 逐像素等价。
  - 双高行编辑帧的增量重放 vs 全量渲染逐像素等价。
  - 形状断言：双高行编辑后两行（上下半）均整行脏（轮 7 既有行为保持）。

### 3.3 SGR 38/48 冒号真彩（Vt102Emulation）

- 复用轮 8 `argSeparators` 设施：SGR 分发循环在既有 38/48 分号定长分支**之前**插入冒号分支（顺序红线同 58）：`38:5:n`、`38:2::r:g:b`、`48:5:n`、`48:2::r:g:b`。
- 空位容忍与已知歧义沿用 58 的已声明口径（恰好 3 分量的 `38:2:0:g:b` 解析正确；0 槽后再有 ≥3 槽的写法按空位误吞，计划注释声明）。
- 分号形式（`38;5;n`、`38;2;r;g;b`）零变化。
- 测试：分号/冒号两形式等价落到同一 CharacterColor；38/48 各一组；回归 `4;3`/`4:3` 区分与 58/59 既有用例不受影响。

## 4. 错误处理

| 情形 | 行为 |
|------|------|
| DECSTBM 切割跨放置 | 各段引用行独立切片，无错位（3.1） |
| 38/48 冒号参数不足 | 忽略该参数，不吞后续独立 SGR（同 58 口径） |
| 双高行与图像/斜体/下划线组合 | 以像素测试裁决，异常则回退保守路径并记录 |
| 38/48 分号形式 | 零变化（既有路径） |
